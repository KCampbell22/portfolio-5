Case study · Personal Portfolio Site

This site, hand-built in plain HTML, CSS and JavaScript with no templates and no framework, and written to load fast and work for everyone.

Type
Personal project
Role
Design & development

Goals

The site is aimed at agencies looking for an extra developer, so it has to show the same things I'd deliver for them: a design built faithfully, fast loading, a good experience on phones and accessibility throughout.

Highlights

  • Swipeable project stack on phones and tablets. The project cards follow your finger with a slight tilt and fly off when released, while the next card grows into place. Vertical swipes still scroll the page, and reduced-motion preferences are respected.
  • Automatic dark mode from 7pm to 7am on the visitor's clock, set before the first paint so the page never flashes, with a manual toggle.
  • A contact form that works anywhere. It's handled by Netlify Forms with a spam honeypot and accessible validation messages. On phones it opens as a bottom sheet you can minimize.
  • Third parties load only when needed. The Calendly booking widget is fetched only when someone clicks "Book a call".
  • Performance basics done properly: self-hosted fonts, responsive WebP images with explicit sizes, lazy-loaded media and no framework to download.
  • Built to be found: structured data, link previews, a sitemap, and service and case-study pages like this one.
