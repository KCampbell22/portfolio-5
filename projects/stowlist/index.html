Case study · Full-stack web app StowList

Stick a QR label on any box, scan it with your phone, and see what's inside. StowList is a mobile-first web app for keeping track of what's stored in boxes, bins and shelves.

The idea

Storage boxes all look the same from the outside. Instead of opening every bin to find one cable, each box gets a printable QR label. Scanning it with any phone camera opens that box's list of contents, ready to add, edit or remove items.

What it does

  • QR labels for every box. A label is created automatically with each box, or print a sheet of blank labels first and set up each box the first time it's scanned.
  • Scan to open. Any phone camera works, since the QR code is just a link. An in-app scanner also recognizes other products' barcodes and QR codes, so existing packaging can be used as a label.
  • Items with photos, with quantities, descriptions and a photo taken straight from the phone camera.
  • Search across every box by item name or description.
  • Printable label sheets laid out four across for sticker paper.
  • Accounts with email and password, including password reset.

How it works

No custom server. The React front end talks to Supabase directly, and the database itself decides who can see what.

Security lives in the database. Every table has a user_id column and Postgres row-level security policies (user_id = auth.uid()), so a query can only ever return the signed-in user's rows, even if the front end had a bug. Item photos sit in a private storage bucket, filed under each user's own folder with matching policies, and are shown through short-lived signed URLs.

Labels are just links. Each QR code holds a short URL. Opening it looks the code up and either opens the box, offers to set up a new box for a blank label, or shows "Label not found". Signed-out visitors are sent to sign in and then returned to the box they scanned.
